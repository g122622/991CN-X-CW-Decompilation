# 用户说明书 ↔ 逆向实现对照

说明书（`官方说明书/markdown版/说明书RJA530830-001V02.md`，由 MinerU 解析）描述了
fx-991CN X 的**外部行为**；本表把它与本工程已还原的函数/变量对应起来，便于从“用户看到
的现象”定位“ROM 里的哪段代码”，也便于反过来用说明书校验命名是否正确。

文献里已经对应的部分（模式字、输入区、变量区）见
[`casio-main符号对照.md`](casio-main符号对照.md) §3；本文只记录说明书能带来的**新增**信息。

## 1. 模式与设定（可直接校验 `0xD111` / `0xD11A` 等）

| 说明书现象 | 说明书给的语义 | 本工程对应 |
|------------|----------------|------------|
| 主菜单 10 个图标 | 计算 / 复数 / 基数 / 矩阵 / 向量 / 统计 / 表格 / 方程·函数 / 不等式 / 比例 | `0xD111` 模式字（C1/C4/02/06/07/03/88/45/4B/4A），`main` 顶层的模式分派循环 |
| 设置 → 输入/输出 | ①数学/数学 ②数学/小数 ③线性/线性 ④线性/小数 | `0xD11E` isMathI；进入统计/基数/矩阵/向量模式时自动切到“线性输入/小数输出” → 对应模式切换里写 `0xD11E` 的代码 |
| 设置 → 角度单位 | ①度 ②弧度 ③百分度 | `0xD11D` angle_unit（4/5/6） |
| 设置 → 显示格式 | 位数(Fix) 0–9 / 科学(Sci) 0–9 / 常规(Norm) 1、2 | `0xD11A` num_format（8/9/0/4）+ `0xD11B` num_format_i → `fmt_number`(0x20462)、`fmt_sci`(0x2051E) |
| 设置 → 分数结果 | 带分数 / 假分数 | `0xD14E` mixed_fraction（`fmt_sci` 里判断 `0xD14E != 0` 时用 0x2E 作小数点无关，分数格式由 0x1C05A 段处理） |
| 设置 → 小数点显示 | 句点 / 逗号 | `0xD11C`：`list_sep_char`(0x20702) 在 0 时返回 `,`，否则 `.` |
| 设置 → 统计 | 开/关 Freq 列 | 统计编辑器列数（x 160 行 / x,Freq 或 x,y 80 行 / x,y,Freq 53 行）对应 `stat_*` 表格行数计算 |
| 设置 → 表格 | ①f(x) ②f(x),g(x) | 表格模式行数上限 45 / 30，对应 `table_*` 的页数常量 |
| 复位 → 全部初始化 / 设置数据 / 存储器 | 三类复位 | `reset_entry`(0x9402) 的初始化表 0xBEE6 与 `ram_clear_all`(0x1F99C) 的多级清零 |

## 2. 数值表示（直接约束 DECIMAL 库的命名）

| 说明书原文 | 含义 | 与 ROM 的关系 |
|------------|------|----------------|
| 计算范围 ±1×10⁻⁹⁹ ~ ±9.999999999×10⁹⁹，或 0 | 指数 2 位 + 10 位尾数 | 与 10 字节 BCD（首 2 字节类型/符号、7 字节尾数、末 2 字节指数）**不一致**：ROM 的 7 字节尾数只是打包后的浮点，说明内部先按 15 位十进制二进制化，10 字节寄存器只是运算缓冲 |
| 内部计算位数 15 位 | 双精度十进制 | `decc_*`/`dec_*` 的中间结果按 15 位；`Rnd` 只影响最后的 10 位 |
| 精度：第 10 位 ±1 | 显示位数 | 与 `fmt_number` 的舍入路径对应 |
| π 内部用 3.14159265358980，e 用 2.71828182845904 | 常量块 | `0x1AF14` 处的常数块 `0x6197723675790101…` 即 π 的打包值，可据此确认该块的用途 |
| Rnd 会改变保留位数 | 舍入 | `eval_round_op_*` / `0x1D780` 段 |

## 3. 错误类型（用于给错误码命名）

说明书列出的错误信息：

| 错误 | 触发条件（说明书） | 建议的 ROM 对应 |
|------|-------------------|-----------------|
| Math ERROR | 中间/最终结果超出范围、输入超出范围、除 0 | `eval_error`(0x108BA) 错误码 1/10 附近（函数内对 `param_1==10 || param_1==1` 调整） |
| Stack ERROR | 数字堆栈/命令堆栈、矩阵/向量堆栈溢出 | 0x1C05A 段的栈深度检查（`stack_depth` 0x90B4 读 SP 相对 0xE3E4） |
| Syntax ERROR | 输入格式错误 | 输入 token 化阶段（`expr_*` / `token_*`） |
| Argument ERROR | 自变量错误（如 log 底数非法） | `eval_error` 的另一分支 |
| Dimension ERROR | 矩阵/向量维数不匹配 | 矩阵运算核心 0x13AC4/0x14B0A 的维数检查 |
| Variable ERROR | SOLVE 对无变量表达式 | SOLVE 实现（提示符 0x971E 段） |
| No Solution | SOLVE 无解 | 同上 |
| Range ERROR | 表格行数超限 | 表格模式页常量 |
| Time Out | 微分/积分未满足结束条件 | 积分/微分实现（tol 比较） |
| （假锁机） | 变量$ 写入导致白屏 | 变量 0x4D/$ 的特殊类型，可对照 `0xD318` 不稳定字符 |

## 4. 输入区与显示（校验 200 字节缓冲区的用法）

| 说明书 | 本工程 |
|--------|--------|
| 一次最多输入 199 个字符；每字节一个数/符号，函数占 2–13 字节；剩 10 字节时光标变■ | `0xD180` 输入区 200 字节；`input_max_len`(0x9B6E) 返回 200/0x32/0x31 |
| 数学模式下输入高度最多两屏（63×2 点） | 绘制时按 `line_print_col0`/`draw_scaled_char(0x2A048)` 的高度检查 |
| 撤销/重做（撤销最后一次键操作） | `undo` 区 `0xD522..0xD5E9`，`editor_action`(0x94DA) 按操作码分派 |
| 历史记录：按 ↑/↓ 滚动，模式切换/改设置/复位即清空 | `calc_history` `0xD392..0xD521`，每条以 0x23 结尾 |
| 重放：结果屏按 ←/→ 编辑上次表达式 | `replay_buf` `0xD248`（回放区）与 `replay_save` `0xD84C` |
| 光标变宽表示从输入区第 189 字节开始 | `0xD155` cursor_position；输入区第 189 字节宽光标阈值 |

## 5. 功能与函数的对应（补充命名线索）

- **Pol/Rec**：说明书强调“计算结果分别存入 x、y”，可据此确认变量写回间址（`var_x`/`var_y` 的槽位）。
- **Ran# / RanInt#**：三分位随机数与区间整数，随机种子在 `0xD310..0xD319`（前 8 字节 + 2 字节），
  对应 `rand_seed` 注释可从“10 字节”改为“8+2”。
- **Q₁/Med/Q₃、min/max**：统计模式 `0x2A318/0x2A428` 构造的 10 字节描述可直接对应。
- **基数模式 32 位符号扩展**：说明书给出 BIN/OCT/HEX 的补码范围，对应基数模式的
  符号扩展开关（`0xD11C` 之外的独立标志）。
- **方程/函数模式**：联立 2–4 元、2–4 次多项式 → `0x27284 table_edit_main2`、
  `0x256E0 stat_main_loop` 附近的方程族。
- **矩阵 MatA..D / MatAns、向量 VctA..D / VctAns**：变量区 0xD31A 起每变量 10 字节，
  矩阵槽另存于 `0xB4/0xBE` 偏移（`mat_slot_copy_*`）。
- **科学常数 47 个（CODATA 2010）、公制转换（NIST SP 811）**：分别对应 ROM 里的
  常数表与公制转换表区（0x3FFC0 附近的数据段）。
- **自检（DIAGNOSTIC）**：说明书“假设计算器发生故障之前”一节的自检流程即
  `diagnostic_mode`(0x22040) → `diagnostic`(0x2209E)，校准后已恢复真实符号名。
